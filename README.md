# Hi, I'm Rick 👋

I started out in Information Science and kept following the problem to its next layer.
A dataset needed cleaning. The cleaning needed a model. The model needed GPUs, a
serving stack and someone to keep it running. Since 2019 I've been working my way down
that chain, and these days I build document AI for environments where data can't leave
the building.

That mostly means fine-tuning LLMs and vision-language models and getting them into
production. I have an MSc rather than a PhD, and I'm happy being an engineer who reads
papers rather than the other way around.
